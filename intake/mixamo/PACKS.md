# Mixamo packs in this project

Each pack's clips by the name a role uses (`AnimationSet.roles`: `&"walk_f": "mixamo/RFP_WalkForward"`).
Machine-readable: `packs.json` (same folder). A clip shared by several packs is imported once, under the
first pack's prefix (Rifle 8-Way Locomotion = Pro Rifle: both list the RFP_ clips). Clips downloaded before
the packs (B_, M_, R_, Z_, N_, S_, T_, U_, PR_ ... prefixes) are not listed here; R_* are 19 of the Rifle
8-Way clips under older names (the bladed stance uses them).
